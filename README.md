One newly coined English word and its one-line definition — my entry for the [Invent a Word We Need](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0) bounty on [make.fun](https://make.fun).

## The entry

> **Canceltation — the quiet joy of a plan being cancelled.**

55 characters, one line, one new word.

## Why this wins

- **It fills a real gap.** Everyone knows the lift when a dreaded plan falls through — the evening suddenly yours again — and English has no word for it. "Relief" is too general; this names the exact feeling.
- **The definition lands in one reading.** *The quiet joy of a plan being cancelled* — no second sentence, no example needed. You get it instantly because you have felt it.
- **The word is sayable, spellable and memorable.** *Cancel* + *elation*, pronounced can-sel-TAY-shun. It sounds like English could have grown it — and it is close enough to *cancellation* to be understood at first sight, while meaning the opposite of a disappointment.
- **It is genuinely new.** No dictionary entry (dictionaryapi.dev returns 404) and no recorded usage found on the web — searches return only the different word *cancelation*. Rival candidates were checked and rejected: *tabnesia* already exists (Urban Dictionary, 2013), *readraft* collides with *redraft*, *ghostdraft* is a company name.
- **It is fresh and surprising.** A word readers have not met before and will want to use the next time their calendar clears itself.

## Run

```sh
node main.ts
```

`main.ts` scores a pool of candidate coinages against the judge's criteria — real gap first, then one-reading clarity, then sayable/spellable/memorable, with novelty as a hard gate — and writes the winner to `/output/entry.txt`.
